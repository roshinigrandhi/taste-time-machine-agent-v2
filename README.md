Taste Time Machine Agent

Discover your taste across time and places! Taste Time Machine Agent uses your favorite artists, movies, foods, and places to explore your preferences and suggest new discoveries inspired by different eras and cultures.

Live Demo

https://taste-time-machine-a-h599.bolt.host

Features

- Enter your favorite artists, movies, foods, and places.
- Discover recommendations based on your taste.
- Explore inspirations from different eras and locations.
- Get ideas for a weekend plan.
- Qloo API integration through a Supabase Edge Function.

Tech Stack

- React
- TypeScript
- Vite
- Supabase Edge Functions
- Qloo Hackathon API

Run Locally

1. Clone this repository.
2. Install dependencies using "npm install".
3. Configure the required Supabase environment variables.
4. Configure the "QLOO_API_KEY" secret securely in Supabase.
5. Start the frontend using "npm run dev".

Never expose API keys or secrets in frontend code or commit them to GitHub.
